# Linux Practice Projects

Longer-form builds than the [Practice Labs](/labs) — these are multi-session projects you build
up over several sittings, the kind of thing worth putting in a portfolio. Every project follows
the same shape: Goal, Requirements, Suggested Approach, Stretch Goals, and Related Modules.

## Beginner

- **[Dotfiles Repo with Aliases and a Custom Prompt](beginner/dotfiles-repo-with-aliases-and-custom-prompt.md)** — a version-controlled shell setup you can drop onto any new machine.
- **[File Organization and Backup Script](beginner/file-organization-and-backup-script.md)** — sort files automatically and back them up on a schedule.
- **[SSH Key-Based Access to a Personal Server](beginner/ssh-key-based-access-to-a-personal-server.md)** — provision a server the way a real handoff should look: non-root, key-only.
- **[System Information Dashboard Script](beginner/system-information-dashboard-script.md)** — a clean, at-a-glance view of a system's health.

## Intermediate

- **[Bash-Based Server Health-Check and Alerting Script](intermediate/server-health-check-and-alerting-script.md)** — detection plus alerting, tuned to avoid noise.
- **[Centralized Log Viewer and Rotation Pipeline](intermediate/centralized-log-viewer-and-rotation-pipeline.md)** — aggregate, rotate, and search logs from multiple services.
- **[Deploy and Reverse-Proxy a Web App with Nginx](intermediate/deploy-and-reverse-proxy-a-web-app-with-nginx.md)** — from "runs on my machine" to a real service behind Nginx and TLS.
- **[User and Permissions Onboarding Automation Script](intermediate/user-onboarding-automation-script.md)** — automate the repetitive, error-prone parts of adding a new team member.

## Advanced

- **[Containerize a Full App Stack, Then Port It to Kubernetes](advanced/containerize-and-deploy-a-full-app-stack-docker-compose-to-kubernetes.md)** — the same stack on Docker Compose and on a single-node cluster.
- **[CI/CD Pipeline That Deploys to a Cloud VM](advanced/build-a-cicd-pipeline-that-deploys-to-a-cloud-vm.md)** — push to deploy, with a real, tested rollback path.
- **[Harden and Audit a Server Against a CIS-Style Checklist](advanced/harden-and-audit-a-server-against-a-cis-style-checklist.md)** — apply and then independently verify a security baseline.
- **[Centralized Monitoring and Alerting Stack for a Multi-Server Fleet](advanced/centralized-monitoring-and-alerting-stack.md)** — Prometheus and Grafana, tuned against alert fatigue.
