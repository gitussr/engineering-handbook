# Linux Cheat Sheets

Ten quick-lookup references, one per topic area — every command links back to the full topic page
when you need the explanation, not just the syntax.

## Sheets

- **[Linux Commands](linux-commands.md)** — navigation, viewing/finding files, text processing, compression, comparing files.
- **[Networking](networking.md)** — IP and interfaces, connectivity testing, DNS, ports and connections, firewalls.
- **[Permissions](permissions.md)** — the rwx model, chmod, chown/chgrp, umask, SUID/SGID/sticky bit, ACLs.
- **[Regex](regex.md)** — anchors, character classes, quantifiers, groups, and common patterns for grep/sed/awk.
- **[SSH](ssh.md)** — connecting, key management, file transfer, tunneling, config, hardening.
- **[systemctl](systemctl.md)** — service control, status and logs, unit files, dependencies and targets.
- **[Cron](cron.md)** — crontab syntax, managing your crontab, system-wide cron, at/anacron, systemd timers.
- **[Package Managers](package-managers.md)** — apt/dpkg, dnf/yum/rpm, snap/flatpak, building from source.
- **[Docker Basics](docker-basics.md)** — images and containers, running/inspecting, Dockerfiles, networking, volumes, Compose.
- **[Git Cheat Sheet](/developer-essentials/git-cheat-sheet)** — the one sheet that lives in Developer Essentials rather than the core roadmap, cross-listed here so all ten sheets are reachable from one hub.
