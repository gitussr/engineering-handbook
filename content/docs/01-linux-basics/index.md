# Linux Basics

Module 01 of 34 · Stage: Beginner · **Pilot module — canonical template for all other modules**
([quality audit](../../../architecture/11-module-01-audit.md))

Before installing anything or opening a terminal, you need a correct mental model of what Linux
is. This module builds that model. It is intentionally light on commands — the few that appear
are read-only identification commands used as illustrations, not a tutorial. Full CLI teaching
starts in Module 03.

## What you should be able to do after this module

- Explain what Linux is without confusing kernel, OS, and distribution.
- Name the major distribution families and say which one a given job would use.
- Explain why almost all production Linux work happens over a CLI, not a GUI.
- Know what `/etc`, `/var`, `/home` etc. broadly mean before Module 05 goes deep on them.
- Pick a distro to install for Module 02, based on your career target, not habit.
